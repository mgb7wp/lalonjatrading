# Configuración fija de los tests

Copia de `config/` tomada al hacer la tarea A3 de `PLAN.md`. Los tests cargan
esta carpeta y no la tuya, así que puedes cambiar capital, mercados o
comisiones en `config/` sin que se rompa ningún test.

No la actualices para seguir a `config/`. Tócala solo cuando un test necesite
un parámetro nuevo (por ejemplo, porque el código exige una clave que antes no
existía) y en ese caso cambia solo lo imprescindible.
